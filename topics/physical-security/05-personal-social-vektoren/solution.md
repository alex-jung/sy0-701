# Lösung – Übung 05: Personal & menschliche Vektoren

## 1. Vektoren

| Vektor | Kurz |
|--------|------|
| Tailgating | unbefugt hinterher durch die Tür |
| Impersonation | gibt sich als Handwerker/Kollege aus |
| Shoulder surfing | liest PIN/Passwort mit |
| Dumpster diving | durchsucht Müll nach Infos |
| Baiting | „verlorener" USB-Stick als Köder |
| Badge cloning/theft | Badge kopieren/stehlen |
| Unattended workstation | ungesperrter PC |
| Unsecured documents | sensible Papiere offen liegen |

## 2. Prinzip/Problem

- Tailgating/Impersonation → **Hilfsbereitschaft/Autorität/Vertrauen**.
- Shoulder surfing/Unattended/Unsecured docs → **Nachlässigkeit**.
- Dumpster diving → **mangelnde Entsorgung** (kein Shredding).

## 3. Gegenmaßnahmen

| Vektor | Organisatorische Control |
|--------|--------------------------|
| Tailgating | Mantrap + Awareness „keine Fremden mitnehmen" |
| Impersonation | Visitor management/Verifikation/Escort |
| Shoulder surfing | Privacy Screens, PIN verdecken |
| Dumpster diving | Shredding sensibler Dokumente |
| Baiting (USB) | USB-Policy, Fundstücke nie einstecken |
| Unattended workstation | Auto-Screen-Lock, Clean Desk |

## 4. Clean-Desk/Awareness-Policy (Beispiel)

1. Bildschirm beim Verlassen sperren (Win+L), Auto-Lock aktiv.
2. Keine Passwörter/Notizen sichtbar; sensible Papiere wegschließen.
3. Besucher anmelden/begleiten, Badges nicht weitergeben.
4. Fremde freundlich ansprechen/verifizieren; niemanden „mitnehmen".
5. Sensible Dokumente/Medien shreddern statt in den Papierkorb.

## Hinweise / Troubleshooting

- Technische Controls (Badge/Mantrap) + **Awareness** nötig – Menschen umgehen sonst die Technik.
- Physisches Social Engineering nutzt dieselben Hebel wie digitales (`social-engineering`).
- Clean Desk/Screen Lock sind billige, wirksame Quick Wins.
